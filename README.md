# Dashboard ODP & Homepass

Dashboard interaktif visualisasi data ODP (Optical Distribution Point) dan Homepass jaringan FTTH.

## Cara Menggunakan di GitHub Pages

1. Buat repository baru di GitHub (atur visibilitas ke **Public** agar GitHub Pages gratis aktif).
2. Ekstrak file ZIP ini, lalu unggah seluruh isinya (`index.html`, `.nojekyll`, `README.md`) ke dalam repository tersebut.
3. Buka menu **Settings** > **Pages** di repository GitHub Anda.
4. Pada bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**.
5. Pilih branch `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu 1–2 menit hingga tautan website aktif muncul di bagian atas halaman Settings > Pages.
